# Changelog — ТСН Менеджер

## [4.1.0] — 2026-06-11

### 🔴 Критичне
**Telegram-моніторинг проблемних міток і монтажу встик**
- ✅ Нова вкладка в popup: **Налаштування Telegram** — введіть токен бота і Chat ID групи монітору
- ✅ Кнопка 🔍 **Визначити** — автоматично знаходить Chat ID після додання бота в групу
- ✅ Кнопка 📨 **Тест** — перевіряє зв'язок з Telegram (відправляє тестове повідомлення)
- ✅ Токен **НЕ** зберігається в коді і репозиторії — лише локально у браузері

### 🎯 Найголовніше: звіт про видео без пауз
**Видео змонтоване ВСТИК** — коли природних пауз нема, мітки ставити нікуди:
- Коли автопілот знайшов, що позицій для реклами немає: **критичний звіт** у Telegram з 🔴 іконкою
- **Що показує звіт:**
  - 📹 назва відео, хронометраж, посилання на редактор
  - 🎬 скільки міток мало бути, що саме він шукав, з якою чутливістю
  - ⚠️ наслідок: у цьому відео РЕКЛАМИ НЕ БУДЕ
  - 👉 рекомендація: поставити вручну або повернути монтажерам на переправку
- Звіт шлеться автоматично під час автопілота, максимум 1 раз на відео

### ⚠️ Додатково: монтаж встик при частковій вставці
- Коли естественних пауз менше 30% від потреби (бот вставляє «запасні» в найтихіші місця):
  - У звіті про вставлені мітки додається блок **«Увага — монтаж встик»** з деталями
  - Пояснюється, що запасні мітки можуть показуватись рідше
- В історії popup: такі відео помічені 🔴 **ВСТИК** з кількістю незастрахованих міток

### 🐛 Виправлено
- **Статус кроків плану:** кроки завершення трансляції (end) тепер коректно помічаються ✅/❌ залежно від результату, не завжди ✅ (пункт 3 з попереднього оновлення)
- **Підрахунок проблем:** у звітах про вставку враховуються ВСІ проблеми без дублювання

### 📊 Нові дані в звітах
- Початок аналізу: `state.analysisMeta` тепер містить `realPauses` (природні паузи) і `backupCount` (запасні мітки)
- Telegram-звіти: поле `kind` розрізняє 'insert' (звичайна вставка) та 'no_spots' (критична ситуація)
- Історія у popup: остатні 50 інцидентів, остатні 5 видні в попапі з датою, назвою відео, статусом ✈️/⚠️

### 🔧 Технічне
- Manifest: додано `https://api.telegram.org/*` до host_permissions
- popup.html: нова вкладка Telegram з інтуїтивним UI для налаштувань
- analyzer.js: збір подій до state.tgEvents, критичний звіт при `maybeFullAutoRun` без позицій
- background.js: 3 нові обробники (`mra_tg_report`, `mra_tg_test`, `mra_tg_detect_chat`), функції buildTgReport/tgApi/pushTgHistory
- Дизайн: вкладка Telegram стилізована під систему popup, toggle для показу/приховування токена

## Як оновитись

1. **Скачайте** розширення і перезавантажте у `chrome://extensions`
2. **Настройте Telegram:**
   - Створіть бота через [@BotFather](https://t.me/BotFather) в Telegram
   - Додайте його в групу моніторингу
   - Напишіть в групу будь-яке повідомлення
   - У popup → **Telegram** → вставте токен → **🔍 Визначити** → **📨 Тест** → **💾 Зберегти**

3. **Перевірте** на відео без пауз — автопілот має одразу відписати критичне попередження в групу
